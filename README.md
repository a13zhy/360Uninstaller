# 残留清理卫士 ResidualCleaner

Windows 10 / 11 上用于深度卸载 360 系软件、清理安装残留的桌面工具。不调官方卸载器，直接逐项拆除进程、服务、计划任务、启动项、目录、DLL 与驱动、注册表、快捷方式；无权访问的文件先接管所有权再强删，仍删不掉的登记到下次开机前由系统删除。界面配色跟随系统的深/浅色模式与强调色。

## 当前版本

**v1.2.9.261117**（开机巡检小窗 · 清理后询问重启 · 整盘 360 目录清扫 · 支持 20 款应用）

## 功能

- **扫描**：注册表卸载项、安装目录、进程、服务、驱动、计划任务、启动项、DLL、快捷方式，覆盖 20 款 360 组件。
- **卸载**：按固定管线拆除（进程 → 服务 → 计划任务 → 启动项 → 目录 → 文件/DLL → 注册表 → 快捷方式 → 复查），删注册表前自动备份，失败项归类归因。
- **一键清除**：底部“360 一键全部移除”一次清空全部组件，清完自动跳残余检查。
- **整盘 360 目录清扫**：枚举各盘一级 360 目录、Program Files、ProgramData、AppData、桌面/下载/文档与临时目录；命中目录整体一项，父子去重。
- **强力删除**：常规删除 → 结束占用进程 + `takeown` / `icacls` 接管 → 仍被锁则写 `PendingFileRenameOperations`，下次开机由系统删除。
- **开机巡检**：可登记下次登录时在右下角弹出巡检小窗（430×238，带扫描动画与进度），列出残余并等你确认后清理；默认不启用，随时可关。
- **重启询问**：清理完成才问要不要重启，选“是”执行 20 秒倒计时，`shutdown /a` 可撤销。
- **系统配色**：读 `AppsUseLightTheme` 与系统强调色，深/浅色自动跟随；对话框文字颜色全部显式指定，不发灰。
- **真实图标**：安装目录里能找到 exe / ico 的，列表直接显示程序自己的图标。
- **检查更新**：从 GitHub Releases 拉版本，可下载并静默安装后重启。
- **托盘常驻**：关闭窗口不退出，任务在后台跑；托盘菜单可扫描 / 巡检 / 开机巡检开关 / 查更新 / 退出。
- **日志**：控制台实时输出，同时落盘到 `%APPDATA%\ResidualCleaner\logs\`（含注册表备份与 crash.log）。

## 安全边界

- 不做后台静默批量删除：每一项都要你先看过、再确认；巡检扫到的东西同样要确认。
- 不自动重启、不做重启循环、不注册后台服务。
- 不默认开机自启。开机巡检只在你显式勾选并确认后登记（优先计划任务，最高权限启动），界面里一键可撤销。
- 被内核自保护锁住的文件只登记“下次开机由系统删除”，不反复硬干。

## 使用

1. 下载 Release 里的 `ResidualCleaner.exe` 或 `ResidualCleaner-v1.2.9.261117-win64.zip`，双击运行（启动时请求管理员权限）。
2. 首次启动会弹免责声明，勾选“我已了解”后进入主界面。
3. 扫描完勾选要卸的应用 → “卸载选中应用”，或直接用底部“360 一键全部移除”；想先看全盘有什么，点顶栏“深度扫描”。
4. 卸载完成自动弹残余检查小窗，勾选后删除；之后会问要不要重启。
5. 想让它下次开机再复查一遍，点顶栏“巡检：关”徽章或托盘里的“开机自动巡检”打开开关。

> 需要管理员权限才能动服务和受保护目录。非管理员启动时顶栏显示“受限模式”，点一下可提权重启（会保留 `--boot-scan` 参数）。

## 从源码构建

```powershell
python -m venv .venv
.venv\Scripts\pip install PySide6==6.12.0 Pillow pyinstaller
.venv\Scripts\python tools\make_icon.py
.venv\Scripts\pyinstaller --noconfirm --onefile --windowed --uac-admin ^
  --name ResidualCleaner --icon assets\app_icon.ico ^
  --add-data "assets;assets" main.py
```

`assets/` 不提交到仓库，图标由 `tools/make_icon.py` 现场生成，CI 也是这么做的。

## 界面

- 左侧主界面：读数条 + 应用列表（真实程序图标，取不到才用字母徽章；状态/占用列）+ 底部宣传条（360 全家桶一键清除）；
- 右侧控制台：等宽字体日志流、扫描进度、已清理/失败/释放空间三列读数；
- 巡检小窗：扫描指示环 + 百分比 + 细节行 + 4px 进度条 + 查看清单 / 立即清理；
- 配色跟随 Windows：深/浅色与系统强调色自动同步，方角细线、无卡片阴影；1240×860 起可缩，最低 1080×720。

## 安装包与产物

## 许可

个人使用，按现状提供，删错东西自己负责（删前会列清单让你确认）。与奇虎 360 无任何关系，仅清理其残留。
